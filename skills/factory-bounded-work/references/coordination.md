# Carry plural and interrupted work

Use independent workers only where independence or required judgment earns the additional context, time and coordination. Partition actual writable subjects before serialising a shared surface; retain serialisation for real invariants. Delegate the concern, exact subject/revision, permitted effects, verification obligations, return address and stop condition. The parent remains accountable for convergence.

Resolve models and carriers through AIKit, delegation/authority through Actuation and material execution through its native owner. A nested wrapper inherits its commission; it does not recursively spawn merely because its instructions describe an agent. Preserve one writer for each shared mutable subject unless the owner provides a verified concurrency contract.

Track cumulative use and retries against the actual commission. Reconcile a partial prior run before repeating an effect. Native execution identity, receipts and current subject state determine recovery; process liveness or PID alone cannot establish ownership. Restart must not replenish a consumed grant or silently restore revoked authority.

On interruption, stop new dependent effects, request cancellation through the selected harness protocol and observe its result. Account separately for pending work, active tool/process termination and retained artifacts. A detached view is not cancellation; an accepted cancellation command is not proof of quiescence. Late child output remains attributable evidence and must be checked against the current subject before incorporation.

Converge through Factory's obligations and inspect actual returned artifacts. If a required branch fails or lacks evidence, retain that standing in the whole. Return a concise account of useful progress and the exact unresolved condition; avoid redundant prompts for permission already granted.
